# 🛒 Shoply - Full Stack Ecommerce Platform

A modern Full Stack Ecommerce application built using **Django REST Framework** and **React**. This project demonstrates a production-ready backend with JWT Authentication, PostgreSQL, Cloudinary image uploads, and a responsive React frontend.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/Thunderboalt25/ecommerce-backend.git
```

## Backend Setup

```bash
cd ecommerce_backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

## Frontend Setup

```bash
cd ecommerce_frontend

npm install

npm run dev
```
